# 📡 EMONA Trainer 101 Simulation

## 🧠 Overview

This project provides an interactive simulation of the **EMONA Telecoms-Trainer 101 kit**, designed to help students and engineers understand fundamental concepts in telecommunications systems without requiring physical hardware.

It enables users to virtually build circuits, connect modules,.
